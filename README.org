#+TITLE: org-show-and-tell
#+AUTHOR: Alexandre Moreno

An opinionated Org mode presentation package featuring an integrated
teleprompter.

* What it does

- *Title & Agenda Slides:* Automatically generates a title cover from =#+TITLE:=
  / =#+AUTHOR:= headers and an agenda slide from your document headings.
- *Smart Subheadings:* Displays parent-heading breadcrumbs on sub-slides for
  context.
- *Teleprompter:* Syncs private notes from =#+begin_notes= blocks to a dedicated
  presenter buffer.
- *Clean Visual Layout:* Centers slides with custom margins, hides heading
  asterisks (=*=), block tags (=#+begin_src=), line numbers, cursors, and
  fringes.
- *Theme & UI Restoration:* Temporarily applies a presentation theme and
  restores your exact buffer state on exit.
- *Evil Navigation:* Maps =h= / =j= / =k= / =l= and =q= to slide navigation.
- Uses buffer narrowing to isolate each slide.

* Doom Emacs Setup

Add to ~packages.el~:

#+begin_src elisp
(package! org-show-and-tell :recipe (:host github :repo
  "moleike/org-show-and-tell"))
#+end_src

Configure in ~config.el~:

#+begin_src elisp
(use-package! org-show-and-tell :commands (org-show-and-tell-mode) :init (map!
  :leader :desc "Toggle Presentation" "t P" #'org-show-and-tell-mode))
#+end_src

* Speaker Notes & Teleprompter

1. Add notes to your slides:

#+begin_src org
,#+TITLE: Presentation Title
,#+AUTHOR: Alexandre Moreno

,* Main Topic
,** Sub-topic Title Slide content goes here.

,#+begin_notes
Speaker notes for this slide.
,#+end_notes
#+end_src

2. Start the presentation: ~M-x org-show-and-tell-mode~ (or ~SPC t P~).

3. For external displays: run ~M-x clone-frame~ and move the new window to your
   projector.

4. Launch the teleprompter on your laptop: ~M-x
   org-show-and-tell-presenter-notes~. This opens a =*Presenter Notes*= split
   that updates automatically as you navigate.
